## HogsFix 0.1

First release. Supports GOG `warhogs_.exe` and the no-CD `Warhogs.exe` (Sep 2000 retail build).

Install: extract `dinput.dll`, `HogsFix.asi`, `HogsFix.ini` into the game folder and start the game.

- Stable start, alt-tab and minimize on Windows 10/11 without wrappers
- AI pigs move again, no terrain flicker
- Widescreen up to 2048 px (Hor+), battle at 60 FPS, fast menus
- CD music from OGG, XInput gamepad with PlayStation layout
- Windowed mode, no CD check, portable

`dinput.dll` is Ultimate ASI Loader v9.7.4 (x86, MIT).
